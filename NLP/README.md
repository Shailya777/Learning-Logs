# Natural Language Processing (NLP) Learning Journey

This section documents my transition from Computer Vision (CNNs) to understanding how machines process and generate human language. Having mastered the fundamentals of Deep Learning with TensorFlow, I am now applying those concepts to sequential data.

## 🚀 Roadmap
1. **Text Preprocessing:** Tokenization, Stop word removal, Stemming/Lemmatization.
2. **Vectorization:** Bag of Words (BoW), TF-IDF.
3. **Word Embeddings:** Word2Vec, GloVe, FastText.
4. **Sequence Models:** RNNs, LSTMs, GRUs, and Bi-Directional LSTMs.
5. **Modern NLP:** (Planned) Transformers and LLMs.

## 🛠️ Tech Stack
* **Languages:** Python
* **Frameworks:** TensorFlow/Keras
* **Libraries:** NLTK, Spacy, Scikit-learn, Gensim
